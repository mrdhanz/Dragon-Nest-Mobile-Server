## Описание

Серверная часть игры **Dragon Nest Mobile** отвечает за обработку игровой логики, хранение данных и взаимодействие с клиентом. Проект был частично рефакторизован, и все необходимые `.exe` файлы были собраны, что позволяет запускать сервер без дополнительной компиляции.

---

## Требования

Для запуска сервера необходимы следующие компоненты:
- **MySQL 8.0**: Сервер базы данных.
- **Visual Studio 10 (C++ 10)**: Для работы с исходным кодом сервера (если требуется модификация).
- **Python 3.12**: Для выполнения вспомогательных скриптов.
- **Git**: Для клонирования репозитория.

## Настройка сервера

1. **Распаковка файлов**  
   Первым делом необходимо распаковать все тяжелые файлы с помощью утилиты `LFSUtility.bat`. Запустите этот файл из корневой директории проекта.  
   ![LFSUtility.bat](Screenshots/LFSUtility.png)

2. **Настройка MySQL**  
   - Установите и запустите сервер **MySQL 8.0**.
   - Настройте подключение к базе данных с параметрами:
     - Адрес: `root@127.0.0.1`
     - Пароль: `""` (пустой пароль).  
     Если вы хотите использовать пароль для своей базы данных, необходимо изменить параметры подключения во всех конфигурационных файлах `.xml`.  
     ![Конфигурация MySQL](Screenshots/MySQLConfig.png)

3. **Инициализация базы данных**  
   - Запустите файл `INITIALIZE_DATABASE.bat`. Этот скрипт автоматически создаст все необходимые базы данных, игровые серверы и пользователя.
   - Для изучения и добавления других серверов или пользователей ознакомьтесь с файлом `DataBaseInits/5. InitServerData.sql`.  
   ![INITIALIZE_DATABASE.bat](Screenshots/InitDataBase.png)

## Запуск сервера

1. **Запуск сервера**  
   После настройки базы данных запустите файл `START_SERVER.bat`.  
   - Должно появиться 8 экземпляров `cmd`, каждый из которых отвечает за свою логику сервера.  
   - Если создалось меньшее количество окон, проверьте корректность настройки MySQL.  
   ![START_SERVER.bat](Screenshots/StartServer.png)

2. **Проверка работы сервера**  
   Если все запустилось корректно, сервер готов к работе.

## Подключение клиента

1. **Запуск клиента**  
   Перейдите в клиентскую часть проекта и запустите игру.  
   - Для тестового входа используйте:  
     - Логин: `Test`  
     - Пароль: `12345`  
   - В дальнейшем вы сможете создавать свои аккаунты.  
   ![Экран входа](Screenshots/LoginScreen.png)

2. **Проверка подключения**  
   Убедитесь, что клиент успешно подключается к серверу и переходит на экран входа в игру.  
   ![Экран входа](Screenshots/LoginScreen1.png)
